# Bit-Clip Lab data: Banjo-Kazooie · N64 NTSC (US 1.0)

Data files for the [Bit-Clip Lab](https://kweber1.github.io/bitclip-lab/?v=ntsc) viewer (the viewer and the tools that make these files are in [kweber1/bitclip-lab](https://github.com/kweber1/bitclip-lab)). Each game version has its own repository so each gets its own 1 GB GitHub Pages site; the viewer loads from all of them on the same `kweber1.github.io` address.

NTSC results for every Banjo-Kazooie room: `data/map<map>.ntsc.wasm` (gzipped JSON: NTSC holds and clips per crack; the room geometry and the PAL results are in bitclip-lab-bk-pal).

Files end in `.wasm` so GitHub Pages serves the gzipped bytes as they are. No game art is published here.
